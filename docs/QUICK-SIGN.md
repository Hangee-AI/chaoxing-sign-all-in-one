# 一键拍照签到（手机上传照片版）

> 适用：普通群 / 院系群里的「拍照签到」卡片。
> 旧流程要「抓链接 → 复制 → 打开工具 → 粘贴 → 选图 → 提交」，现在压缩成「双击一个 bat → 手机上选图 → 点提交」。

## 怎么用

1. 双击项目根目录的 **`一键拍照签到.bat`**
   - 脚本会先自愈：把上一次可能残留的手机代理清掉（这一步能防住「手机突然上不了网」）
   - 如果签到工具（`http://localhost:8050`）没在跑，会自动拉起来
   - WSL 里的 PostgreSQL 没起来也会自动拉起
2. 脚本开始抓包后，**在手机上打开那个签到卡片**（进入拍照签到页即可，先别拍照）
3. 抓到链接后脚本**立刻恢复手机网络**，然后自动在手机浏览器打开签到页：
   `http://127.0.0.1:8050/quick-sign?link=...`
4. 在手机页面上点「选择照片」，从相册挑一张，点「提交签到」
5. 页面直接显示学习通返回的原文（`签到成功` / `您已签到过了` / `签到已结束` …），同时写进数据库的签到记录

## 为什么这样更稳

- **先确认 8080 真在监听，才去设代理**：旧脚本 `start mitmdump` 之后睡 4 秒就设代理，mitmdump 没起来时手机会被指向一个死代理（`net::ERR_EMPTY_RESPONSE`，表现就是「网页无法打开、什么都上不去」）。
- **无论成功/超时/异常都恢复**：脚本主体包在 `try/finally` 里，抓完立刻 `http_proxy :0` + `adb reverse --remove-all` + 关 mitmdump。
- **启动先自愈**：每次运行开头先清一遍残留代理，所以即使上次崩溃了，重跑一次就恢复正常。
- **手机端上传**：不需要把照片传到电脑。页面通过 `adb reverse tcp:8050` 暴露给手机，手机浏览器选相册照片直接 POST 到本机。

## 手动兜底

| 情况 | 做法 |
| --- | --- |
| 手机突然上不了网 | 双击 **`还原手机网络.bat`**（清代理 + 清 reverse + 关 mitmdump） |
| 链接已经拿到了 | `一键拍照签到.bat` 或 `pwsh -File capture-tool\quick-sign.ps1 -Link "<链接>"`，跳过抓包直接开页面 |
| 只想看看页面长什么样 | `pwsh -File capture-tool\quick-sign.ps1 -SkipCapture -Link "<链接>" -NoOpen`（不设代理、不打开浏览器） |
| 抓包超时 | 确认手机打开的是签到**卡片**页面；实在抓不到就手动复制链接，用 `-Link` 跑 |

## 相关文件

- `一键拍照签到.bat`：入口（调用下面的 PowerShell）
- `capture-tool/quick-sign.ps1`：真正的逻辑（自愈 / 抓包 / 恢复 / 打开手机页面）
- `pages/quick-sign.vue` + `server/api/quick-sign.post.ts`：手机端「选照片 → 提交签到」页面和接口（不要求 next-auth 登录，本机自用）
- `还原手机网络.bat`：紧急恢复
